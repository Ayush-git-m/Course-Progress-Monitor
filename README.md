# Course Progress Monitor

A Python Tkinter application for recording, updating, searching and analyzing
student course progress.

## Problem Statement
Students complete different units, activities or learning tasks at different
rates. An instructor wants to see who is progressing steadily and which parts
of the course have lower completion.

## Objective
Develop an application that records course progress and helps the instructor
monitor completion patterns.

## Main Technologies
- Python
- Tkinter
- Pandas
- NumPy
- Matplotlib
- CSV file handling

## Project Modules
- `main.py` - Tkinter GUI and application entry point
- `data_manager.py` - persistent CSV data operations
- `analytics.py` - progress calculations and analysis
- `reports.py` - Matplotlib visual reports
- `validation.py` - input validation

## Data
- `data/students.csv`
- `data/progress.csv`

The remaining functionality will be implemented module by module.
